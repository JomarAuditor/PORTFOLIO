    Featured project

    ChemScan

    HTML · CSS · JavaScript · Supabase · Vercel

    A QR code inventory system for school science labs. Scan any bottle to instantly see what it is, which shelf it belongs on, its hazard information, and first aid steps. Lab admins log in to add chemicals and generate new QR codes.

    View code on GitHub

    How it works

    1. Register. Admin adds a chemical and receives a QR code.
    2. Print. The code is attached to the bottle.
    3. Scan. Any phone shows shelf, hazards, and first aid.
